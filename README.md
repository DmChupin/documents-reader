## Document reader

Приложение позволяет просматривать загруженные документы, добавлять к ним аннотация, а также экспортировать документ в формат JSON

### Путь http://localhost:4200/reader/:id/view , где id 1 или 2 (моковые данные) 


Особенности реализации:

1. Загружаем документ в виде изображений, выводим через for(...) {<img />}
2. Аннотации - отдельный компонент Annotations. Для передвижения аннотаций реализована директива Drag. У аннотации можем менять положение, изменять текст, удалять
3. Выделил 3 сервиса для бизнес-логики - сервис для работы с аннотациями, сервис для работы с загруженным документом, сервис для работы с "читалкой" - непосредственно самим приложением
4. Реализовал 1 мок-сервис для имитации работы с api.
5. Для отображения содержимого аннотации использовал textarea (согласно ТЗ "Пользователь может добавлять аннотации в виде текста.")

Плюсы реализации:

1. Отзывчивость приложения
2. Простота реализации
3. Поддержка мобильных устройств
4. Минимальное использование сторонних библиотек (только uuid, т.к. попал на мобильном устройстве в ловушку crypto)
5. Быстродействие
6. Вариант MVP в том случае, если весь функционал будет ограничем чтением и добавлением комментариев, например, ЭДО

Минусы реализации:

1. При желании расширять возможность взаимодействия с документами можно столкнуться со следующими проблемами:
   - Отсутствие возможности редактирования содержимого документов
   - В том случае, если захочется добавить возможность рисования на документе, выделения текста, рисование геометрических фигур и т.д., то для отображения документа лучше бы подошел canvas
2. Хоть и присутствует поддержка мобильных устройств, но, я считаю, что надо придумать алгоритм масштабирования документа и аннотаций в зависимости от разрешения экрана пользователя
3. Нет "ленивой" загрузки файла, соответственно при больших объемах или низкой скорости интернета будут проблемы с отображением. Как вариант использовать библиотеку browser-image-compression или просто добавить skeleton-loader

Известные проблемы:

1. Масштабирование изображения. transform-origin позволяет вставить пару палок себе в колёса
2. Относительное значение высота и ширины аннотаций в зависимости от размеров экрана
3. Предусмотреть различные обработки для тача / мыши
4. Оптимизация размера изображений (описал подробнее выше)
5. Соблюдение размеров страниц при использовании директивы Drag. В данной реализации сделал просто overflow: clip. В идеале надо отслеживать левый и правый край для оси X и верхний и нижний край для оси Y

### Docker
Из корня проекта:
1. docker build -t documents-reader:latest .
2. docker run -p 8080:8080 documents-reader:latest
